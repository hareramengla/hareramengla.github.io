VOICE AGENT — RESPONSE WAVEFORM LIVE

Voice AI Agent Systems

End-to-end conversational voice agents — designed, built, and evaluated from scratch, with no existing playbook to follow.

The problem
Most conversational agents fall apart the moment a real customer goes off-script. Getting them production-ready means more than a clever prompt — it means catching failure modes before a customer does.
What I built
Multiple inbound and outbound voice agents with distinct personas, using prompt and context engineering, function-calling integrations with the Gemini and OpenAI APIs, and language handling for natural conversation flow.
How I evaluated it
Built a structured evaluation pipeline covering 75+ test cases to systematically surface failure modes, tone inconsistencies, and off-script behaviour before shipping changes — then used transcript analysis to drive faster, evidence-based iteration.

EXECUTION SYSTEM — SIGNAL TO ORDER NIFTY · XAUUSD

Algorithmic Trading Systems

Automated trading infrastructure spanning two live markets — Indian equity derivatives and global forex/metals.

The problem
Manual trade execution across fast-moving derivatives and forex markets is slow, inconsistent, and hard to run with discipline. I wanted systems that could take a strategy from signal to execution without emotion in the loop.
What I built
Two automated trading systems: one integrating with Zerodha's Kite Connect API for Indian options (F&O) trading, and another built on MetaTrader 5 for forex and metals — each handling data ingestion, signal generation, order execution, and risk controls.
How it's structured
Credentials and strategy parameters are kept out of the public repo; what's shared is the system architecture — data pipeline, execution logic, and risk management design — so the engineering is visible without exposing the live trading edge.
